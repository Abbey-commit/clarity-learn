# Contributing to ClarityLearn

We welcome contributions to ClarityLearn! Here are some ways you can help:

## Reporting Issues
If you find a bug or have a feature request, please open an issue on GitHub.

## Improving Explanations
Feel free to suggest improvements for existing term explanations or add new terms.

## Code Contributions
If you want to contribute code, please fork the repository and submit a pull request. Make sure to follow the coding standards and include tests for new features.

## Documentation
Help us improve the documentation by suggesting changes or adding new content.

Thank you for your interest in contributing to ClarityLearn!
